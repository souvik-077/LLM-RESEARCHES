# LLM-RESEARCHES

A personal, evolving log of my journey learning about Large Language Models (LLMs) — 
guided study, paper summaries, and day-by-day notes.

## 📓 About this repo

I started with zero background in LLMs. This repo tracks what I'm learning, 
the papers I read, and the tasks I work through, mentored by Dinesh Sir.

Topics covered so far:
- LLM Hallucination
- Knowledge Graphs (KG) & Multi-modal Knowledge Graphs (MKG)
- GraphRAG (Graph-based Retrieval-Augmented Generation)
- KG-Adapters
- Multi-Hop Reasoning
- Datasets used in LLM/RAG research
